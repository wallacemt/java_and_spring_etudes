# Estrutura do projeto

```text
acervo-da-quarentena/
├── docs/
│   └── ESTRUTURA.md
├── src/
│   ├── abstracts/
│   ├── entities/
│   ├── exceptions/
│   ├── utils/
│   └── Main.java
├── test/
│   ├── src/
│   │   └── *Test.java
│   └── MUTACOES.md
├── junit-console.jar
└── PLAN.md
```

- `src/`: código-fonte da aplicação.
- `test/src/`: testes automatizados com JUnit.
- `test/MUTACOES.md`: registro dos testes de mutação manuais.
